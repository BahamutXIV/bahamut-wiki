# Branding assets

These images were created by Bahamut and are configured through ManageWiki. When updating
them, replace the existing uploads using the same filenames to preserve their
configured URLs.

- `Bahamut_Logo.png` and `Bahamut_Logo_2x.png`: transparent 135px and 270px
  exports of the day logo for the sidebar.
- `Bahamut_Favicon.ico`: the blue favicon, with embedded 16, 24, 32, 48, 64,
  and 256px images.
- `Bahamut_Favicon.png`: the supplied 256px blue icon.
- `Bahamut_Apple_Touch_Icon.png`: a 180px RGB export of the blue icon,
  flattened onto black for Apple devices.

The files retain the supplied artwork, resized for their display sizes.
