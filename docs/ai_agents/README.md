# AI contributions

Review AI-assisted changes and be able to explain what changed, why it belongs
here, and how it was checked. The repository scope and checks apply equally
to work done with or without AI tools.

## Writing documentation

Describe current behavior. Keep each fact in one guide and link to it from
other pages. Use concise ASCII prose. Leave out progress reports, private
paths, and narration about the assistant's work. A file in Git does not prove
that its contents are live on the wiki.

Length and punctuation rules are defaults. Preserve technical identifiers and
source details when clarity or correctness requires them.
